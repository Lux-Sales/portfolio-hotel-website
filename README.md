## 🏨 Sobre o Projeto

Este projeto é uma interface web para um hotel de luxo, desenvolvida como parte do meu portfólio pessoal. O objetivo era criar uma experiência de usuário moderna e responsiva, utilizando um conjunto de ferramentas de desenvolvimento de ponta.

A aplicação foi construída com `Vite` para um desenvolvimento rápido, `React` e `TypeScript` para uma base de código robusta e escalável, e `Styled Components` para estilização modular. Os testes são garantidos com `Vitest` e `React Testing Library`, e o deploy foi feito no `Firebase Hosting`.

---

## ✨ Tecnologias Utilizadas

*   **React:** Biblioteca principal para a construção da interface.
*   **TypeScript:** Para adicionar tipagem estática e segurança ao código.
*   **Vite:** Ferramenta de build e desenvolvimento extremamente rápida.
*   **Styled Components:** Para estilização CSS-in-JS, permitindo componentes visualmente isolados.
*   **React Router Dom:** Para gerenciamento de rotas da aplicação.
*   **Axios:** Para realizar requisições HTTP a APIs.
*   **Vitest & React Testing Library:** Para testes unitários e de componentes.
*   **ESLint & Prettier:** Para garantir a qualidade e a consistência do código.
*   **Firebase:** Utilizado para o hosting da aplicação.

## 🚀 Como Executar o Projeto

Siga os passos abaixo para rodar o projeto em seu ambiente de desenvolvimento local.

1.  **Clone o repositório**
    ```sh
    git clone https://github.com/seu-usuario/seu-repositorio.git
    ```
2.  **Instale as dependências**
    <p>Dentro do diretório do projeto, execute o comando:</p>
    ```sh
    yarn install
    ```
3.  **Inicie o servidor de desenvolvimento**
    <p>Este comando iniciará o servidor do Vite em modo de desenvolvimento.</p>
    ```sh
    yarn dev
    ```
4.  **Crie a build de produção**
    <p>Para gerar os arquivos otimizados para produção, execute:</p>
    ```sh
    yarn build
    ```
